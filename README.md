# Мастерская педагога

Сайт Андреева Дмитрия Викторовича для GitHub Pages.

Публичные страницы и изображения размещаются на GitHub Pages. Только опубликованные записи и открытый профиль читаются с отдельного сервера через GET /api/public-site. Черновики и права автора не передаются. При недоступности сервера используется снимок публичных данных на момент сборки. Файлы скачиваются с прежнего сервера. Кабинет автора использует прежний адрес и вход ChatGPT.

Репозиторий: dmitriy5885as-design/dmitriy5885as-design.github.io. В настройках Pages выбрать GitHub Actions. Сборка: npm ci, npm run build. Рабочая база, секреты и серверный код в этот репозиторий не включаются.

После публикации записей в кабинете новые материалы появляются без повторной сборки сайта (обычно в течение минуты). Снимок для автономного просмотра обновляется при новом экспорте и сборке.

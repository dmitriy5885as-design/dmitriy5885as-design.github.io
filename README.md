# Мастерская педагога

Персональный сайт-портфолио Андреева Дмитрия Викторовича.

**[Открыть сайт →](https://dmitriy5885as-design.github.io/)**

## О сайте

«Мастерская педагога» — пространство для представления профессиональной деятельности, педагогического опыта и авторских материалов. Сайт объединяет информацию об авторе и его публикации в одном месте.

Здесь можно познакомиться с портфолио, прочитать опубликованные материалы и скачать доступные файлы.

## Технологии

Сайт создан на React и TypeScript, собирается с помощью Vite и размещается на GitHub Pages.

## Локальный запуск

Для работы требуется Node.js версии 22.13 или новее.

```bash
npm ci
npm run dev
```

## Сборка

```bash
npm run build
```

Для просмотра собранной версии:

```bash
npm run preview
```
